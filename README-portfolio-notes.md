# Personal portfolio starter

A responsive, single-page portfolio starter for someone presenting to recruiters, hiring managers, and prospective clients. It uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Preview

Open `index.html` in a browser. The site includes CSS artwork, responsive layouts, subtle scroll and hover animations, and a light / dark theme switch in the header. The selected theme is saved in the browser when storage is available.

## Personalize before publishing

1. Search `index.html` for square-bracket placeholders such as `[YOUR ROLE]` and replace them with accurate details.
2. Replace `YOUR NAME`, `YN`, `hello@example.com`, location, and social profile links.
3. Replace the experience entries with your real title, employer, dates, scope, and specific outcomes. Remove any metric you cannot substantiate.
4. Turn each project into a useful mini case study: challenge, your contribution, collaborators, and outcome. Remove confidential details unless you have permission to publish them.
5. Add your résumé PDF at `assets/your-name-resume.pdf` or update the link to its real location.
6. Add your home-page portrait as `assets/profile.jpg` (or change the image path in `index.html`). The About image is an abstract visual placeholder; replace it with a real personal image if you prefer.
7. Write the three About story chapters in your own voice.
8. Add recommendations only with the person's permission. Remove the quote band if you do not have a suitable endorsement.
9. Update the page title and description in the `<head>` for search and link previews.

## Later additions

The navigation and section pattern can grow into separate `blog/`, `writing/`, or `now/` pages. Keep case studies and writing focused on evidence relevant to the work you want.
